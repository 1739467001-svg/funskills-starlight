# 繁星之夜 · FunSkills 决赛星河长廊

一个以「繁星 / 恒星 / 星座」为主题的决赛作品展示落地页，收录 37 份进入决赛的 Skill 作品。

## 看点
- **首屏星空**：Canvas 实时星空 + 流星 + 星轨光环，数字滚动。
- **星河长廊**：3D Coverflow 大轮播，自动旋转 / 拖拽 / 方向键 / 圆点导航。
- **星座图谱**：按 5 条赛道（电商出海 / 金融投资 / 效率工具 / 内容创作 / 生活成长）筛选，卡片随滚动逐颗"点亮"。
- **灯箱详情**：点任意作品查看高清海报 + 简介 + 标签 + 选手，支持 ‹ › 与 Esc。
- 纯静态，无需构建，移动端自适应。

## 本地预览
双击 `启动预览.command`，或在本目录运行：
```bash
python3 -m http.server 8000
```
然后浏览器打开 http://localhost:8000

## 目录
- `index.html` 页面结构
- `assets/style.css` 样式
- `assets/app.js` 交互（星空 / 轮播 / 网格 / 灯箱）
- `assets/data.js` 作品数据（标题 / 选手 / 简介 / 赛道）
- `assets/works/*.jpg` 海报（含 `thumbs/` 缩略图）

> 部署：把整个文件夹上传到任意静态托管（GitHub Pages / Vercel / Netlify / 对象存储）即可。
